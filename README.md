# Tiszazugi Földrajzi Múzeum – Cégjelzés-katalógus

Ez a csomag a múzeum cégjelzés-katalógusának teljes, képfájlokkal együtt használható változata.

## Tartalom

- 2492 eredeti képfájl
- `data/gyujtemeny.json` – a fájlnevekből létrehozott kereshető adatbázis
- `index.html` – a katalógus
- `css/style.css` – megjelenés
- `js/gyujtemeny.js` – keresés és részletek
- `import.html` – későbbi új képek importálásához
- `images/` – az eredeti képfájlok, változatlan fájlnévvel

## Keresés

A katalógusban kereshető többek között:

- rövid és teljes gyártónév
- fantázianév
- város
- ország
- Quelle / forrás
- jelzéstípus
- iniciálé
- az eredeti teljes fájlnévben szereplő bármely szöveg

A 13 jelzéstípus a megadott dokumentum szerinti rendszerhez igazodik. Az olyan részletes megjelölések, mint `centre decal`, `box decal`, `motor decal` vagy `stand sign`, az eredeti fájlnévben és a kódnevek között is megmaradnak, miközben a kereső az alap kategóriához is hozzájuk rendeli őket.

## Fontos

Az eredeti fájlnevek megmaradnak, mert a fájlnév a katalógus adatainak fontos része.

A képek összesített mérete körülbelül 878 MB. GitHub Pages használata előtt érdemes ezt figyelembe venni; a végleges publikálásnál szükség esetén készíthetünk webre optimalizált másolatokat is, amelyek lényegesen kisebbek, miközben a nagy felbontású eredetik külön megőrizhetők.


## Webes képváltozat

A katalógus a `images-web/` mappából tölti a webre optimalizált JPEG-eket.
Az eredeti képek változatlanul megmaradnak az `images/` mappában.

- Feldolgozott képek: 2492
- Eredeti képméret összesen: 837.7 MB
- Webes képméret összesen: 178.8 MB
- Maximális hosszú oldal: 1600 px
- JPEG minőség: 82
